# Bellhop

Bellhop is a Chrome/Edge MV3 extension that adds an "Import into Privilege
Cloud" button to Idira Marketplace product pages, so a connection component
or platform installs directly into the tenant's Privilege Cloud instead of a
manual download-then-upload round trip.

Not affiliated with or endorsed by Palo Alto Networks or CyberArk.
