# Security

Bellhop is an unsupported spike, not a maintained product. There is no SLA and no guaranteed
response time.

## Reporting an issue with this extension

Open a GitHub issue on this repository, or email tim@iosharp.com for anything you'd rather not
post publicly (e.g. a permission-model or auth flaw). Include the extension version
(`extension/manifest.json`) and enough detail to reproduce.

## What not to report here

This repository is not affiliated with Palo Alto Networks or CyberArk. Issues with the Idira
Marketplace, Privilege Cloud, or the Idira Identity Security Platform itself belong to the
vendor's own support channels, not this repository.
